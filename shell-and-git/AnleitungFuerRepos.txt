1. meine GitHub Seite öffnen / repo erstellen ohne README.md
2. Git Bash öffnen und Sicherstellen dass ich im richtigen Ordner bin
3. git init
4. git add . (für den ersten Commit vorgemerkt)
5. git commit -m "Initial commit"
6. GitHub Repo verbinden, wird angezeigt sobald neues Repo erstellt wird (persönliche SSH URL) kopieren
7. git remote add origin SSH URL aus dem Repo einfügen
8. git branch -m main
9. git push -u origin main

Befehle für Git Bash

In Ordner navigieren
pwd Zeigt, in welchem Ordner du gerade bist
ls Zeigt Dateien und Ordner im aktuellen Ordner
cd ordner Wechselt in einen Ordner
cd .. Geht einen Ordner zurück
cd ~ Geht in deinen Benutzerordner
clear Leert das Terminal

Dateien und Ordner
mkdir test Erstellt einen neuen Ordner
touch test.txt Erstellt eine neue Datei
rm test.txt Löscht eine Datei
rm -r ordner Löscht einen Ordner inklusive Inhalt
cp datei.txt backup.txt Kopiert eine Datei
mv alt.txt neu.txt Verschiebt/benennt eine Datei um

Git - Repository überprüfen
git status Änderungen im Projekt
git log Zeigt die Commits an
git log --oneline ist nur etwas übersichtlicher
git remote -v Zeigt an, mit welchem GitHub-Repository mein lokaler Ordner verbunden ist
